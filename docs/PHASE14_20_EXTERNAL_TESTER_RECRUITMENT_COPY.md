# Phase 14.20 — External Tester Recruitment Copy Pack

**목적:** 실제 외부 테스터(1~3명) 모집을 위한 짧고 실무적인 모집 문구 템플릿.  
**범위:** 초대제(Invite-only) 클로즈드 베타 모집용 카피만 포함.  
**중요:** 공개 출시/유료 라이브 런칭을 의미하지 않음.

---

## 1) 모집 포지션/자격 (명시용)

다음 중 하나에 해당하는 분을 우선 모집:

- 온라인 판매자(스마트스토어/자사몰/오픈마켓)
- 소상공인/1인 브랜드 운영자
- 크리에이터/콘텐츠 셀러
- X(트위터) / 인스타그램 / 블로그 / SNS에 홍보성 콘텐츠를 실제로 올리는 분

권장 조건:

- 최근 1개월 내 SNS 홍보 포스팅 경험
- 간단한 피드백(스크린샷/시간/재현 단계) 제공 가능

---

## 2) 제한사항 (모든 채널 공통 고지)

- 현재 **초대제 클로즈드 베타**입니다 (공개 서비스 아님).
- 실발행 검증은 현재 **X 중심**입니다.
- 결제/빌링은 **라이브 유료 런칭 상태가 아닙니다**.
- 테스트 중 이슈 제보 시 **스크린샷 + 발생 시간 + 사용 계정 이메일** 공유를 요청드립니다.

---

## 3) 디스콰이엇 스타일 모집글 (국문)

제목:
`[초대제 베타 테스터 1~3명 모집] SNS 홍보 콘텐츠 실제 운영자 찾습니다`

본문:
```text
안녕하세요, Promi 팀입니다.

현재 초대제(Invite-only) 클로즈드 베타를 소규모로 운영 중이며,
실제로 SNS에 홍보 콘텐츠를 올리는 분 1~3명을 추가로 모시고 있습니다.

[이런 분이면 좋아요]
- 온라인 판매자 / 소상공인 / 1인 브랜드 운영자
- X, 인스타그램, 블로그 등에서 홍보성 포스팅을 직접 하시는 분

[테스트 범위]
- 초대 링크로 가입/로그인
- 콘텐츠 생성/수정
- 예약 업로드 및 히스토리 확인
- (실발행 검증은 현재 X 중심)

[중요 안내]
- 공개 런칭 전 단계의 초대제 베타입니다.
- 결제/빌링은 라이브 유료 런칭 상태가 아닙니다.
- 버그 제보 시 스크린샷/시간/계정 이메일 공유를 부탁드립니다.

관심 있으시면 댓글 또는 DM 주세요. 간단히 운영 중인 채널을 알려주시면 순차 안내드리겠습니다.
```

## 4) 네이버 카페/커뮤니티용 안전 문구 (국문)

```text
[초대제 베타 테스터 모집 / 1~3명]

안녕하세요. 소규모 홍보 자동화 도구(Promi) 클로즈드 베타 테스터를 찾고 있습니다.
실제로 SNS에 상품/서비스 홍보 글을 올리는 분이면 좋습니다.

대상:
- 온라인 판매자, 소상공인, 1인 브랜드, 크리에이터
- X/인스타/블로그 등 홍보 포스팅 운영 경험자

테스트 내용:
- 초대 링크 가입/로그인
- 홍보 문구 생성
- 예약 등록/업로드
- 결과(히스토리) 확인

안내:
- 공개 서비스가 아닌 초대제 베타입니다.
- 실발행 테스트는 현재 X 중심입니다.
- 결제는 라이브 유료 런칭 상태가 아닙니다.

참여 가능하신 분은 댓글이나 쪽지로
"운영 채널 + 업종 + 테스트 가능 시간대" 남겨주세요.
```

대신 실제 사용 피드백(스크린샷/시간/계정 이메일)을 부탁드려요.

괜찮으시면 안내 드릴게요 🙂

## 10) 운영 메모 (스팸/과장 방지)

- “혁신”, “압도적”, “완전 자동” 같은 과장 표현 피하기
- 공개 오픈/유료 런칭 뉘앙스 금지
- 1~3명 소규모/초대제/테스트 목적을 문장 앞부분에 명시
- 메시지 길이는 짧게, 행동 요청은 1개만 제시(DM 또는 댓글)
- 동일 커뮤니티 도배 금지(채널별 1회 + 후속 답변 중심)
